# Changelog

## 0.1.0 - 2026-11-08

- Initial portable skill with 18 security-risk playbooks, Java/JVM and
  Node.js/TypeScript adapters, and eight scoped/phased prompts.
- Evidence-led reviews with confidence, counterevidence, visible unknowns, and
  separate conditional findings; report-only by default.
- Bounded local inventory/discovery, scanner-result normalization, and a
  non-overwriting manual installer. No runtime dependencies or bundled scanners.
- GitHub/Skills CLI distribution and Codex/Claude repository-hosted plugin
  catalogs backed by the same skill directory.
- Apache-2.0 licensing, installation notices, automated package checks, and
  tagged GitHub releases with source ZIPs and SHA-256 checksums.

See [qualification](QUALIFICATION.md) for validation evidence and limitations.
