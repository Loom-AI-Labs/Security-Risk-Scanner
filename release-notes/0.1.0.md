# Security Risk Scanner 0.1.0

An AI-assisted security review skill from Loom AI Labs for Codex and Claude Code.
It covers 18 risk families with Java/JVM and Node.js/TypeScript guidance, phased
review prompts, and bounded local helpers. Search matches are leads, not verdicts.

## Install

With Node 22.20+ and Git, from the project you want to review:

```sh
npx skills@1.7.6 add Loom-AI-Labs/Security-Risk-Scanner@v0.1.0 --skill security-risk-review -a codex claude-code
```

The release ZIP also supports the dependency-free manual installer on Node 20+.
Codex and Claude plugin catalogs are included. See the
[README](https://github.com/Loom-AI-Labs/Security-Risk-Scanner/blob/v0.1.0/README.md) and [distribution guide](https://github.com/Loom-AI-Labs/Security-Risk-Scanner/blob/v0.1.0/docs/DISTRIBUTION.md) for
installation, invocation, update, and removal instructions.

## Safety And Qualification

Report-only by default; no target builds, live probes, scanner installation,
credential validation, or automatic fixes. The package itself has no telemetry,
MCP service, or added tool grants. Assistant/model data controls still apply.

Deterministic tests and the independent 40-excerpt synthetic evaluation are
different evidence types, not a real-world accuracy guarantee. See
[qualification](https://github.com/Loom-AI-Labs/Security-Risk-Scanner/blob/v0.1.0/QUALIFICATION.md) and [security guidance](https://github.com/Loom-AI-Labs/Security-Risk-Scanner/blob/v0.1.0/SECURITY.md).

The ZIP contains only tracked release files. `SHA256SUMS` verifies archive bytes;
it is not an independent signature. License: Apache-2.0.

Official third-party directory listing/approval is not included in this release.
